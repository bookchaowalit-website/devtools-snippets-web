# DESIGN.md

## Overview

Specimen / Index is a dark code-library surface: a small local shelf on the left and one readable code specimen on the paper sheet to the right.

## Colors

- Black `#0d1110` is the editor ground; panel `#141b18` holds the library rail.
- Paper `#e7e9df` is reserved for the selected specimen sheet.
- Mint `#9de8b3` marks selection and primary code emphasis.
- Orange `#f0a15e` marks protocol boundaries and count metadata.

## Typography

- Trebuchet MS gives the index a compact utilitarian voice without defaulting to a generic developer landing page.
- Courier New is the code, protocol, label, and tag voice.
- The specimen title is large and black on paper; code is always read in a stable monospace measure.

## Layout

- The hero is open and quiet, then the filter rail and specimen stage form the main product surface.
- The library remains a persistent index on desktop; on mobile it becomes the first section before the selected sheet.
- MCP is a labeled boundary in the rail, not an unearned product promise.

## Elevation & Depth

No shadows or blur. Contrast between black library, mint selection rule, and paper sheet creates the depth hierarchy.

## Shapes

Square borders, hairline green rules, an unrounded paper sheet, and compact rectangular controls. No icon tiles or rounded card stacks.

## Components

- Search field and language/category filters.
- Selectable specimen index with title and language.
- Numbered code sheet with copy action and tags.
- MCP endpoint note describing the local protocol surface.

## Do's and Don'ts

- Do preserve the code as the hero artifact and make the full shape readable.
- Do label data and protocol limits honestly.
- Don't invent a large remote snippet catalog or hide the demo boundary.
- Don't decorate code with generic gradient cards or tool icons.
